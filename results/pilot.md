## What this run actually shows

1. **The harness discriminates.** B0 → 100 % ASR; B1 → 0 % ASR but 62.5 % utility
   and 37.5 % FPR, i.e. the deny-all sanity baseline is correctly punished.
2. **Parameter validation alone carries no security benefit here** (B3 = 100 % ASR):
   every attack uses allowlisted parameters, so only provenance can separate it
   from a benign call. This is the ablation the paper needs.
3. **Boundary taint changes the outcome** (G: 0 %, utility 100 %).

## Why G's 0 % is *not* a result

The scenario declares `tainted = true` for attacks and `false` for benign trials,
so the gate is being asked to separate a label it was handed. A scripted gullible
agent always attempts the attack. This measures **enforcement correctness and
harness plumbing**, not detection of real injection in real models.

## Not measured (limitations, binding)

Real LLMs; adaptive adversaries; endorsement/RQ3 (`E_bar`); human principals;
external benchmarks (AgentDojo/MCPTox); consistency/witness verification
(`ISSUE-006`); cross-session provenance laundering; latency on a defined storage
profile. Each must appear in the paper's limitations.
